# Инфо ПТК

Веб-приложение для первокурсников Политехнического колледжа НовГУ (Великий Новгород).
Учебный проект команды «Субо».

Открыть: https://tadeqqqq.github.io/infoptk/

Внутри: безопасность (инструкции МЧС и экстренные номера), правила колледжа, педагоги с контактами,
где поесть и заняться спортом рядом, звонки, чек-лист первой недели и словарик первокурсника.

Данные о сотрудниках — с открытого портала НовГУ (portal.novsu.ru). Инструкции — по памяткам МЧС России.
